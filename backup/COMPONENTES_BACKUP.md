# Componentes en Backup

Este directorio contiene componentes que han sido identificados como no utilizados o poco utilizados en el proyecto actual.

## Componentes movidos a backup

- Cart.js
- CartManager.js
- Header.js
- ProductManager.js

## Razones para el movimiento al backup

1. **Componentes reemplazados**: Algunos componentes han sido reemplazados por nuevos componentes ES6
2. **Componentes no utilizados**: Componentes que no están siendo utilizados en ninguna parte del sitio
3. **Componentes obsoletos**: Componentes que han sido reestructurados o reemplazados

## Cómo restaurar componentes

Para restaurar un componente desde el backup:

1. Copiar el componente desde `backup/components/` al directorio de componentes apropiado
2. Actualizar las referencias en el código
3. Verificar que el componente funcione correctamente
